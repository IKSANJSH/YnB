# 💰 머니업 (MoneyUp)

**사회초년생·20·30대를 위한 금융습관 코칭 앱**

금융지식(73.6점)과 실제 금융행동(64.7점) 사이의 격차를 좁히기 위해 만든 서비스입니다.
"알아도 실천 못하는" 문제를 신용점수 진단 → 금융 퀴즈 → 모의투자 → AI 코치 흐름으로 해결합니다.

## 핵심 기능

### 🏠 홈 — 금융 뉴스 & 정보
- 연합뉴스·한국경제 RSS를 실시간으로 가져와 카테고리별(전체/금융/증권/산업/IT/부동산)로 필터링
- 관심 기업명 검색 시 관련 뉴스만 조회 (Google 뉴스 검색 연동)
- 뉴스 썸네일 이미지 표시
- 20·30대를 위한 금융 정보 카드 (적립식 투자, 청년도약계좌, 비상금 통장, 신용점수 관리)

### 📊 신용점수 분석
- 다른 앱(토스, 뱅크샐러드 등)에서 확인한 신용점수를 입력하면 즉시 진단
- 점수 구간(관리 필요/보통/우수)별 맞춤 코칭 미션 제공 + 체크리스트
- 점수 게이지, 다음 등급까지 진행률 바
- 또래(같은 나이대) 평균과 비교
- 재입력 시 성장 기록 그래프(최고점, 회차별 증감) 표시

### ❓ 금융 O/X 퀴즈
- 매매 용어·시장 구조·채권/금리·펀드/ETF·신용점수·예적금·세금·암호화폐·경제지표 등을 다루는 100개의 O/X 퀴즈 문제 풀
- 라운드마다 10문제를 랜덤 출제, 정답 시 해설 제공

### 📈 모의투자
- 온보딩에서 실시간모드/가상모드 선택 → 시작 자금 설정(100만~10억원) → 관심종목 1~5개 선택 순으로 진행
- **실시간모드**: 국내 주식(네이버 금융 실시간 시세), 해외 주식(미국 티커, 환율 적용 원화 환산, 장마감 시 마지막 종가 + "장마감" 표시), 코인(업비트 공개 시세)을 그대로 반영
- **가상모드**: 실제 가격 변동성을 흉내 낸 합성 시뮬레이션(드리프트 + 평균회귀)으로 등락을 재현해 반복 연습이 가능
- 보유 종목이 평단가 대비 ±5% 이상 급등락하면 실제 사례(파업, 금리 인상 등)를 반영한 이유와 함께 팝업 알림
- 매수/매도 시 수량 입력창에 잔액 기준 "최대" 수량 자동 계산 버튼 내장
- 평단가, 손익률, 총자산·수익률 자동 계산, 거래 후 시세 자동 새로고침

### ✨ AI 투자 조언 (AI 코치)
- 모의투자 화면 옆에 떠 있는 AI 코치가 사용자가 직접 입력하지 않아도 화면 상태(선택 종목·보유 현황·손익)를 읽고 먼저 코멘트
- 종목 선택 시 / 매수·매도 체결 시 자동으로 코멘트 갱신, 관련 뉴스 헤드라인을 근거로 좋은 신호인지 나쁜 신호인지 설명
- 이전 코멘트를 기억해 반복하지 않고 새로운 정보·관점 위주로 설명, 대화창에 직접 질문을 이어서 입력 가능 (멘토링 스타일 연속 대화)
- 특정 종목 매수/매도를 지금 하라고 추천하지 않으며, 실제 투자 결정은 공인된 금융 전문가와 상담하도록 안내하는 가이드라인 준수

## 기술 스택

- **프레임워크**: Next.js (App Router)
- **언어**: TypeScript / React
- **API 연동**: 업비트 공개 시세 API, 네이버 금융 국내·해외 실시간 시세 및 종목 검색, 네이버 환율(USD/KRW), 연합뉴스·한국경제 RSS, Google 뉴스 검색 RSS, NVIDIA NIM(OpenAI 호환 엔드포인트) 기반 AI 코치 챗봇
- **상태 관리**: React useState (별도 백엔드/DB 없이 클라이언트 상태로 동작)

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 **http://localhost:3000** 접속.

AI 코치를 사용하려면 프로젝트 루트에 `.env.local` 파일을 만들고 아래 값을 채워야 합니다.

```
NVIDIA_API_KEY=your-nvidia-nim-api-key
```

## 폴더 구성

```
app/
├── page.tsx                  ← 전체 화면 (홈/신용점수분석/퀴즈/모의투자/AI 투자 조언)
├── layout.tsx
├── globals.css
└── api/
    ├── news/route.ts         ← 뉴스 RSS 파싱 API
    ├── stock/route.ts        ← 네이버 금융 국내 주식 시세 프록시 API
    ├── stock-search/route.ts ← 네이버 종목 검색(국내/해외) 프록시 API
    ├── coins/route.ts        ← 업비트 코인 목록/검색 프록시 API
    ├── upbit/route.ts        ← 업비트 시세 프록시 API
    └── coach-chat/route.ts   ← AI 투자 조언 코치 챗봇 API (NVIDIA NIM)
public/
└── moneyup-standalone.html   ← 백엔드 없이 단독 실행 가능한 정적 버전
```

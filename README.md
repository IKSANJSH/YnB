# 💰 머니업 (MoneyUp)

**사회초년생·20·30대를 위한 금융습관 코칭 앱**

금융지식(73.6점)과 실제 금융행동(64.7점) 사이의 격차를 좁히기 위해 만든 서비스입니다.
"알아도 실천 못하는" 문제를 금융정보 → 금융 퀴즈 → 모의투자 → AI챗봇 피드백 흐름으로 해결합니다.

## 핵심 기능

### 🔐 회원가입 / 로그인
- 이메일 + 비밀번호 회원가입, 가입 시 닉네임 설정
- Supabase Auth 기반 이메일 인증번호(OTP) 확인
- 헤더의 계정 버튼 → "회원정보 수정" / "로그아웃" 리본 메뉴 표시. 회원정보 수정 화면에서 닉네임·비밀번호 변경, 로그아웃은 "로그아웃 하시겠습니까?" 확인창을 한 번 거침
- 로그인하면 거래 기록·모의투자 상태·아침 편지·AI 대화 내역이 브라우저가 아니라 **계정에 저장**되어 다른 기기에서도 이어서 사용 가능. 로그인하지 않아도 모의투자 설정(현금·모드·보유종목·관심종목)과 거래 기록·아침 편지는 이 브라우저에 그대로 이어지지만, 다른 기기·브라우저에서는 이어볼 수 없고 캐시를 지우면 함께 사라진다는 안내를 모의투자 진입 시 표시 (체크박스로 "오늘은 다시 보지 않기" 가능)

### 🏠 홈 — 금융 뉴스 & 정보 & 아침 편지
- 연합뉴스·한국경제 RSS를 실시간으로 가져와 카테고리별(전체/금융/증권/산업/IT/부동산/해외뉴스)로 필터링. 원본 매체 RSS를 가져오지 못하면(호스팅 환경에서 차단되는 경우 등) 같은 주제의 구글 뉴스 검색으로 자동 대체해 빈 화면이 뜨지 않도록 처리
- 관심 기업명·분야 검색 시 관련 뉴스만 조회 (Google 뉴스 검색 연동)
- **✨ 맞춤 뉴스**: 비로그인 시 브라우저에 저장된 거래 기록, 로그인 시 계정 DB의 거래 기록을 바탕으로 최근 거래한 종목 관련 뉴스만 모아서 보여줌. 첫 클릭 시 "관심 분야 기반 뉴스이며 거래내역이 없으면 안 보일 수 있다"는 안내 팝업 표시 (체크박스로 "오늘은 다시 보지 않기" 가능)
- 20·30대를 위한 금융 정보 카드 (투자/적금/신용점수/비상금·지출관리, 각 항목 10개 내외) + 새로고침마다 AI가 새로 생성하는 **"오늘의 금융 상식"** 카드. 팩트체크 리스크를 줄이기 위해 금리·금액·기한 등 시기에 따라 바뀌는 구체적 수치는 넣지 않고, 복리·분산투자 같은 시간이 지나도 변하지 않는 원칙만 다루도록 프롬프트로 제한
- **오늘의 투자 편지**: 매일 처음 접속 시 미국/국내 경제 뉴스, 보유·거래 종목 관련 뉴스, 최근 매수·매도 기록과 그 이유를 종합해 "잘한 점 / 아쉬운 점 / 개선하면 좋은 점" 3단 구성의 편지를 AI가 작성. 가장 최근 거래가 **실시간모드**면 뉴스 흐름과 매매 이유가 논리적으로 맞는지를 평가하고, **가상모드**면 가격이 실제 시세가 아닌 연습용 시뮬레이션이므로 실제 뉴스·가격과 연결짓지 않고 매매 이유의 논리성·습관 위주로만 평가. 특정 종목을 사거나 팔라고 추천하지 않음. 하루 한 번만 생성되어 캐시되고 새로고침해도 유지됨

### ❓ 금융 O/X 퀴즈
- 매매 용어·시장 구조·채권/금리·펀드/ETF·신용점수·예적금·세금·암호화폐·경제지표 등을 다루는 100개의 O/X 퀴즈 문제 풀
- 라운드마다 10문제를 랜덤 출제, 정답 시 해설 제공

### 📈 모의투자
- 온보딩에서 실시간모드/가상모드 선택 → 시작 자금 설정(100만~10억원) → 관심종목 1~5개 선택 순으로 진행. 각 단계에서 뒤로가기(이전 단계) 또는 홈으로 나가기 가능
- **실시간모드**: 국내 주식(네이버 금융 실시간 시세), 해외 주식(미국 티커, 환율 적용 원화 환산, 장마감 시 마지막 종가 + "장마감" 표시), 코인(업비트 공개 시세)을 그대로 반영
- **가상모드**: 실제 가격 변동성을 흉내 낸 합성 시뮬레이션(드리프트 + 평균회귀)으로 등락을 재현해 반복 연습이 가능
- 현재 진행 중인 모드가 상단 제목에 "모의투자 실시간모드 / 모의투자 가상모드"로 표시됨
- 보유 종목이 평단가 대비 ±5% 이상 급등락하면 실제 사례(파업, 금리 인상 등)를 반영한 이유와 함께 팝업 알림
- 매수/매도 시 **이유를 반드시 입력**해야 체결되며, 어떤 모드에서 거래했는지 함께 기록됨
- 매수/매도 시 수량 입력창에 잔액 기준 "최대" 수량 자동 계산 버튼 내장
- **거래 캘린더**: 날짜별로 그날의 매수·매도 기록과 이유, 거래 당시 모드(📡 실시간 / 🎲 가상)를 확인 가능. 캘린더에서 날짜별 AI 분석("이 날 조언")과 월별 AI 분석("이번 달 조언")을 각각 요청해 매매 습관 피드백을 받을 수 있음
- **처음부터 다시**: 현재 현금·보유 종목·관심종목 설정을 초기화하고 모드 선택부터 다시 시작. 거래 기록과 캘린더는 그대로 유지됨

### ✨ AI챗봇 (AI 코치)
- 모의투자 화면 옆에 떠 있는 AI 코치가 사용자가 직접 입력하지 않아도 화면 상태(선택 종목·보유 현황·손익)를 읽고 먼저 코멘트
- 종목 선택 시 / 매수·매도 체결 시 자동으로 코멘트 갱신, 관련 뉴스 헤드라인을 근거로 좋은 신호인지 나쁜 신호인지 설명. 실제 검색된 뉴스가 없으면 사실을 지어내지 않고 솔직하게 안내
- 이전 코멘트를 기억해 반복하지 않고 새로운 정보·관점 위주로 설명, 대화창에 직접 질문을 이어서 입력 가능 (멘토링 스타일 연속 대화)
- 특정 종목 매수/매도를 지금 하라고 추천하지 않으며, 실제 투자 결정은 공인된 금융 전문가와 상담하도록 안내하는 가이드라인 준수
- 별도의 "AI챗봇" 메뉴에서도 예산·저축·신용점수·투자 기본기 같은 일반적인 금융 습관 상담 가능. 시황·종목 관련 질문에는 답변 아래 실제로 검색된 뉴스 기사 링크를 함께 보여줘, AI 답변이 가짜뉴스나 오류가 아닌지 원문에서 직접 확인할 수 있음

## 기술 스택

- **프레임워크**: Next.js (App Router)
- **언어**: TypeScript / React
- **인증 · 데이터베이스**: Supabase (Auth 이메일/OTP 로그인, Postgres에 거래 기록·모의투자 포트폴리오·아침 편지·AI 대화 내역을 계정별로 저장, Row Level Security로 본인 데이터만 접근 가능)
- **API 연동**: 업비트 공개 시세 API, 네이버 금융 국내·해외 실시간 시세 및 종목 검색, 네이버 환율(USD/KRW), 연합뉴스·한국경제 RSS(실패 시 Google 뉴스 검색으로 대체), NVIDIA NIM(OpenAI 호환 엔드포인트, `google/diffusiongemma-26b-a4b-it`) 기반 AI챗봇
- **상태 관리**: React useState + Supabase(로그인 시) / localStorage(비로그인 게스트 모드)

브라우저에서 **https://moneyupup.vercel.app** 접속.

## 폴더 구성

```
app/
├── page.tsx                  ← 전체 화면 (홈/퀴즈/모의투자/AI챗봇, 인증 포함)
├── layout.tsx
├── globals.css
└── api/
    ├── news/route.ts         ← 뉴스 RSS 파싱 API (실패 시 Google 뉴스로 대체)
    ├── stock/route.ts        ← 네이버 금융 국내 주식 시세 프록시 API
    ├── stock-search/route.ts ← 네이버 종목 검색(국내/해외) 프록시 API
    ├── coins/route.ts        ← 업비트 코인 목록/검색 프록시 API
    ├── upbit/route.ts        ← 업비트 시세 프록시 API
    └── coach-chat/route.ts   ← AI챗봇 API (NVIDIA NIM)
lib/
├── supabaseClient.ts         ← Supabase 클라이언트 초기화
└── db.ts                     ← 거래 기록/편지/AI 대화/포트폴리오 조회·저장 함수
supabase/
└── schema.sql                ← Supabase 테이블 및 RLS 정책 생성 스크립트
public/
└── moneyup-standalone.html   ← 백엔드 없이 단독 실행 가능한 정적 버전
```
